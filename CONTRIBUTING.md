# Contributing

Thanks for wanting to contribute! This list stays useful only because contributors keep it honest.

## Adding a tool

Open a PR that edits `README.md`. Your suggestion needs to:

1. **Solve a real workflow problem.** Not "AI for X" with no differentiation.
2. **Be currently active.** No dead products, no abandoned betas.
3. **Have a free tier or meaningful trial** wherever possible.
4. **Belong in an existing category.** If it doesn't, propose a new category in your PR.

In your PR description, please include:

- A one-line description of what the tool does
- The category you're suggesting it for
- Why it's better than (or complementary to) what's already listed
- A link to your own use of it (a screenshot, blog post, tweet — anything)

## Removing a tool

If a tool is dead, has gotten worse, or has been replaced by something clearly better, open an issue or PR with the rationale. The 2026 edition has already removed several entries from 2025 for these reasons.

## Style

- Keep descriptions to one line.
- Stick to the existing table format inside each category.
- Alphabetize within a section *only* if you can't make a stronger ordering argument (e.g. "best first").

## Code of Conduct

Be kind, be specific, assume good faith. PRs that disparage tools or maintainers will be closed.
